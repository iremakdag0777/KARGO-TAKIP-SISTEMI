# KARGO-TAKIP-SISTEMI

Bu proje, kargoların kayıt altına alınmasını ve çalışanların kargo işlemlerini düzenli şekilde yönetebilmesini , müşteriler tarafından takip edilmesini ve teslimat durumlarının yönetilmesini sağlayan bir kargo takip sistemi uygulamasıdır. Sistem; Gönderi, Müşteri, Kurye, Araç, Güzergah, Durak, Takip Olayı, Şube, Ücret Tarifesi bilgilerini barındırarak yönetilmeyi amaçlar.
